# Practice 7 · Assume It Will Lie to You

This book once fabricated a scripture. It didn't happen in a chapter; the chapter quoted the verse correctly. It happened in the file we wrote to *prove* the chapter. We keep a provenance file beside every chapter, a record that says *here is the verse, here is the source, here is the exact text we checked.* And one of those proof files, written to guard against exactly this, had invented a version of Doctrine and Covenants 104:11-12 that the manuscript above it had gotten right. The guard had hallucinated. An audit caught it; the same audit found a fabricated chapter anchor a few files over.

Look at how that happened, because it's the whole point. A book about working with AI in the service of the gospel nearly shipped invented scripture, and it did so in the very document whose job was to prevent invented scripture. The confabulation didn't announce itself. It wore the same calm, sourced, footnoted confidence as everything true around it. That is what makes it dangerous: the model is not less convincing when it's wrong.

The seventh practice is a posture to adopt before you start: **assume it will lie to you, and build the gates that catch it.** Not because the model is malicious; it isn't. It generates the most plausible next thing, and the most plausible thing is usually true and occasionally, seamlessly, not. You cannot tell which by reading more carefully, because wrong and right are written in the same hand. You can only tell by *checking against the real source.*

I relearned this from the other direction just days ago. I wrote a quick script to test whether one of our models was streaming output correctly. The script said it was broken, with nothing coming through. I almost wrote the model off. Then we checked it the real way, through the actual parser instead of my hasty one, and the model was fine; my *test* was the thing that lied. The lesson stuck a second time: distrust a bad result from a tool you just built, and verify through the real path, not the convenient one.

What the fabrication bought us, in the end, was the gates. We made provenance a gate instead of a footnote: the verified quote gets read from the source *before* the chapter is accepted, not reconstructed from memory after. We wrote the rule that you read before you quote, every time, no exceptions. We built a small server to fetch scripture straight from the canonical text so checking is one call away. Every scripture in these drafts went through that tool first. The verse the proof file once invented now reads, verifiably: *"a commandment I give unto you, that ye shall organize yourselves and appoint every man his stewardship; That every man may give an account."* I know it is right because I didn't trust my memory. I checked.

The doctrine under this is sober and clarifying. A model stating a falsehood with full confidence is the engineering rhyme of false revelation; a model drifting from its instructions rhymes with apostasy. The book holds that line carefully: these are tools failing under law, not souls falling under sin. But the *defense* is the same one the soul is taught: watch, and verify against the unchanging source. The Gods watched what they had ordered until it obeyed ([Abraham 4:18](../../gospel-library/eng/scriptures/pgp/abr/4.md?verse=18)); [qr](../../gospel-library/eng/scriptures/pgp/abr/4.md?verse=18) they did not assume. (Part Two: Watching, and the failures-as-types passage — illustration, never identity.)

Today the gates are provenance files, a read-before-quoting rule, a verification tool one call away, and a habit of counting citations so none slips through unchecked. The tools will change. The posture won't: assume confident output can be wrong, and build checking into the path so it happens even when you're tired and the deadline is close. *Especially* then.

**Try this.** Take one factual claim the AI gave you today (a quote, a statistic, or an API that supposedly exists) and trace it to the actual source before you use it. Then make that automatic: a rule, a script, a tool, so checking isn't a virtue you summon but a gate the work passes through.

> **Remember:** Assume it will lie to you — not from malice, but because plausible and true are written in the same confident hand, and you can't tell them apart by reading harder. Build the gate: verify against the real source, before you use it, every time. The book that teaches this once fabricated a scripture in the file meant to prevent it. That's why the gate exists.
